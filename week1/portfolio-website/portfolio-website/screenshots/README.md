# Screenshot checklist

Add final screenshots of the deployed portfolio to this folder:

- `home-desktop.png` — desktop full-page homepage
- `home-mobile.png` — mobile homepage
- `projects-section.png` — projects grid and filter buttons
- `contact-page.png` — contact form view

Suggested tools: Chrome DevTools device toolbar, browser full-page capture, or your operating system's screenshot tool. Verify text is readable and crop away unrelated browser/UI areas when appropriate. Capture the real final site after updating contact and social links.
