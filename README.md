# Week 1 Assignments

This repository contains the frontend web development tasks completed during Week 1. The projects focus on core HTML, CSS, and JavaScript concepts, including landing pages, UI styling, and a responsive personal portfolio website.

## Overview

The repository is organized around a single `week1` folder containing multiple practice tasks and one completed portfolio project. The work emphasizes:

- Semantic HTML structure
- Responsive CSS layouts
- Basic JavaScript interactivity
- UI design and page composition
- Frontend portfolio presentation

## How to run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/vedfalke/week1-assignments.git
   ```
2. Open the project folder in your browser or use a local web server such as VS Code Live Server.
3. For the portfolio project, open the `index.html` file inside `week1/portfolio-website/portfolio-website/` in a browser.

## Notes

- This is a static frontend project repository.
- No build tools or package installation are required for most tasks.
- The portfolio project can be deployed using GitHub Pages or any static hosting provider.
